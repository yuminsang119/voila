## 2. 시나리오별 흐름

### 시나리오 A — 카카오톡: 텍스트 질의

```
사용자                카카오 오픈빌더         스킬서버(kakao)      RocheBot
  │                        │                      │                  │
  │─ "대전 내과 병원 찾아줘" ──▶│                      │                  │
  │                        │── POST /skill/chat ──▶│                  │
  │                        │                      │── bot.chat() ───▶│
  │                        │                      │                  │─ 인텐트 파싱
  │                        │                      │                  │  (find_hospital)
  │                        │                      │◀─ 병원 목록 반환 ─│
  │                        │◀── SimpleText JSON ──│                  │
  │◀─ 병원 목록 말풍선 ──────│                      │                  │
  │                        │                      │                  │
  │─ [📍 서구] 버튼 클릭 ──▶│                      │                  │
  │                        │── POST /skill/       │                  │
  │                        │   select_district ──▶│                  │
  │                        │                      │─ 서구 중심 좌표    │

```

```
  │◀─ "병원 8건, 약국 8건 수집" ────│                      │

  │                               │
  │─ [체크 실행] 버튼 ─────────────▶│
  │                               │─ 오늘 날짜 요일 판별
```

```
      │

 hospitals.json      pharmacies.json
      │                    │
      └─────────┬──────────┘
                │
        [CheckerAgent]
     요일/공휴일 판별 → 영업 여부 계산
                │
                ▼
 daily_status.json   pharmacy_status.json
                │
                ▼
     [HospitalDataStore] ←─── 모든 에이전트가 공유

```

## 4. 실행 환경 구성

```
서버 (1대)
├── uvicorn web_app:app --port 8000          ← 모바일 웹
├── uvicorn kakao_skill_server:app --port 8001 ← 카카오 채널
├── python hospital_gradio.py               ← 관리자 UI (port 7860)
└── python -m hospital_agents.main          ← 스케줄러 데몬
        (매일 06:00 수집, 07:00 체크)

외부
├── ngrok http 8000   → https://xxxx.ngrok.io  (모바일 접속용 HTTPS)
├── ngrok http 8001   → https://yyyy.ngrok.io  (카카오 스킬 HTTPS)
├── 카카오 i 오픈빌더  → 스킬 URL 등록
└── HIRA 공공데이터 API 키
    카카오 REST API 키 (주소검색용)
```
